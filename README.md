# Dental Clinic Website

A modern, fast, and fully responsive website for a dental clinic, built using vanilla frontend technologies. The project focuses on clean layout structure, precise styling, and smooth user interactions.

---

## 🚀 Features

* **Responsive Layout:** Works smoothly across all screen sizes (Desktop, Tablet, Mobile) using fluid design and media queries.
* **User Authentication:** Built-in modal tabs for Sign In and Sign Up with dynamic form switching.
* **Patient Dashboard:** Interactive dashboard where patients can view dummy appointments, active prescriptions, and edit their profile details.
* **Appointment Booking:** Fully functional booking form with validation and success/error status handling upon submission.
* **UI Interactivity:** Includes scroll animations (Reveal on Scroll), sticky navbar effects, counter animations for clinic stats, and smooth navigation triggers.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic elements for structured markup.
* **CSS3:** Global styles, custom variables, layout grids, and explicit responsive media queries.
* **JavaScript:** Pure Vanilla JS handling layout states, authentication flow, and local storage.
